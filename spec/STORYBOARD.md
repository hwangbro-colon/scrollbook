# 북북(BookBook) 실제 출시 프로토타입 스토리보드
> 출처: Canva "홈 프로필 탭바 - Instagram 스토리" (7페이지) — 2026-08-15 캡처

## 하단 탭바 (4탭, 전 화면 공통)
`북북(홈/로고)` / `책장` / `(확장 - 추후 자리)` / `프로필`

---

## 1. 스플래시
- 흰 배경, 중앙에 "북북" 로고 텍스트만

## 2. 회원가입 및 로그인
- 플레이스홀더 상태 (세부 UI 미정)

## 3. 북북 사용법 (온보딩 팝업)
- 배경: 스크롤 리딩 화면 (민트그린)
- 상단: "북북" 로고 + "닫기" 버튼(원형)
- 본문 카피:
  - "북북 사용법 (팝업)"
  - "책을 스크롤 해서 읽으세요!"
  - "(너무 불필요하면 나중에 없애는걸로)" ← 팀 메모, 실제 UI 카피 아님
  - "첫 5문장이 마음에 들면 계속 읽고, 아니면 위 책장으로 가서 다른걸 고르세요"

## 4. 스크롤 리딩 화면 (완독 시점)
- 배경: 민트그린
- 상단: "북북" 로고 + "100/100" (진행률, N/N 형식)
- 중앙: "the end" (완독 종료 카피, 플레이스홀더)
- ※ 실제 스크롤 중간 상태(청크 단위 텍스트) 화면은 스토리보드에 별도로 없음 — 완독 모드 최종 상태만 표현됨

## 5. 책장 탭
- 상단: "북북" 로고
- 검색창 (플레이스홀더 "검색창")
- 필터 탭: 전체 / 소설 / 고전 / 로맨스 (전체 선택 상태 = 흰 배경)
- 책 캐러셀: 중앙 강조 + 좌우 부분 노출 카드 (3권 노출)
- 책 정보: "책제목" + "스크롤 수 / 완독 수 / 클릭 수"
- "균형 맞추는 텍스트" 라벨 + 상태 태그: "거의 다 읽은" / "완독"
- 통계 박스 3개(검정 배경): 100% / 0% / 3%

## 6. 프로필 탭
- 상단 민트그린 영역: "북북" 로고
- 흰 카드: 프로필 사진 자리("지 사진") + 초록 버튼 "N권 스크롤"
- 하단 검정 영역:
  - 닉네임: "북딱북딱 (이름)"
  - 소개 박스(초록): "목표 / 자기소개 등등"
  - "총 기록?" 섹션 헤더
  - 읽은 책 리스트(둥근 박스, 초록/검정 스트라이프): 데미안, 인간실격, 노인과바다(날짜: 2026년 8월 17일 예시), 오만과편견, 이방인, 싯다르타

## 7. 설정 (프로필 하위)
- 검정 배경
- 항목: 알림설정(토글/입력 강조), 버전, 문의, 인스타그램

---

## ⚠️ 확인 필요 사항 (진행 전 준민 확인)
1. **컬러 팔레트 충돌**: 스토리보드는 민트그린+검정 배색. 기존 확정 브랜드 컬러(흰/검/주황, 구 팔레트 폐기)와 다름. 어느 쪽이 최신 기준인지 확인 필요.
2. **폰트**: 화면에 들어갈 텍스트(로고, 카피, 버튼 등)에 어떤 폰트/굵기를 쓸지 미정.
3. 스크롤 리딩 중간 상태(청크 텍스트가 실제로 보이는 화면) 목업이 스토리보드에 없음 — 완독 모드 최종 화면만 존재.
4. "(확장)" 탭이 실제로 어떤 기능 자리인지(추후 서재/그룹 등) 미정.
